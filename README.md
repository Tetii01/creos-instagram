# creos-instagram

Imaginile pentru postările de Instagram ale Creos (@creos.ro).
Metricool le preia de aici prin link public, la programare.

Structură: un folder pe zi de postare, `AAAA-LL-ZZ-subiect/`, cu slide-urile numerotate (`01.png`, `02.png`...).
Doar postări de Instagram. Nimic confidențial aici: repo-ul e public.
